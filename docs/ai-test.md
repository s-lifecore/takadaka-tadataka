# AI判定テスト

1. `.env.local` にチームのFirebase設定を記入する（秘密情報はコミットしない）。Firebase AI Logicの有効化はバックエンド担当と確認する。
2. `npm run dev` を実行する。
3. 表示されたポートの `/ai-test.html` を開く。
4. `public/ai-test-samples/` のPNGを選択し、「AIで採点する」を押す。
5. 同じ画像・お題を5回採点し、最大差を確認する。
6. 画像を変える前に「記録をJSONで保存」で結果を保存する。

サンプル：apple_good（高）、apple_rough（中〜高）、circle（中〜低）、triangle（低）、blank（ほぼ0）。これは期待する順位であり、検証済みの得点ではない。

仮の合格基準：似た絵ほど高得点、5回の最大差がおおむね10点以内、画像にある特徴を理由にする、0〜100の整数が返る。

`src/lib/aiPrompt.ts` を一項目ずつ変更し、同じ画像で再検証する。モデル名（VITE_GEMINI_MODEL、未指定時gemini-2.5-flash）、プロンプトの版、実施日も記録する。temperature=0でも再現性は保証されない。

エラーは画面とブラウザのConsoleで確認する。403は利用権限やApp Check、404はモデル名、429は利用枠をバックエンド担当と確認する。通信失敗は0点として記録しない。

この画面は検証用。公開ビルドにも含まれるため、本番公開時の取り扱いはチームで決める。
